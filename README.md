# CrediFácil - Créditos al alcance de todos

## 🚀 Descripción
Aplicación móvil para gestión de créditos y préstamos. Permite a los usuarios solicitar créditos de forma fácil y rápida, mientras que los administradores pueden gestionar todas las solicitudes.

## 📱 Características

### Para Usuarios
- Solicitud de créditos en línea
- Verificación de identidad con INE
- Seguimiento del estado de su crédito
- Login con huella digital / Face ID
- Chat con soporte
- Notificaciones en tiempo real

### Para Administradores
- Panel completo de gestión de usuarios
- Estados de crédito: Recibido, En revisión, Aprobado, Rechazado, etc.
- Generador de comprobantes SPEI
- Generador de contratos
- Exportación a Excel
- Centro de comando en vivo
- Sistema de supervisores
- Diagnóstico y autoreparación

## 🛠 Tecnologías
- **Frontend:** Expo (React Native)
- **Backend:** FastAPI (Python)
- **Base de datos:** MongoDB
- **Autenticación:** JWT + Biometría

## 📦 Instalación

### Backend
```bash
cd backend
pip install -r requirements.txt
python server.py
```

### Frontend
```bash
cd frontend
npm install
npx expo start
```
