📱 Guía de Instalación

Sigue estos sencillos pasos para instalar la app

1

Descarga el archivo APK

Descarga el archivo CrediFacil.apk desde el enlace que te compartimos por WhatsApp o correo.

2

Permite orígenes desconocidos

Ve a Ajustes → Seguridad y activa Orígenes desconocidos o Instalar apps desconocidas.

3

Abre el archivo descargado

Busca el archivo en tu carpeta de Descargas y tócalo para iniciar la instalación.

4

Confirma la instalación

Presiona Instalar cuando aparezca el mensaje. Espera unos segundos a que termine.

5

¡Listo! Abre CrediFácil

Busca el ícono verde de CrediFácil en tu pantalla y regístrate para comenzar.

⚠️
Importante: Si tu teléfono muestra una alerta de seguridad, es normal. Solo presiona "Instalar de todos modos" para continuar.
